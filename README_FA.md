# ContactFlow CRM — راهنمای کامل و قدم‌به‌قدم

برنامه‌ی دسکتاپ **بومی ویندوز** (C# / WinForms، .NET 8) برای مدیریت مخاطبین
واقعی. خروجی نهایی یه فایل تک‌تکه‌ی `ContactFlowCRM.exe` هست که مستقیم روی
ویندوز اجرا می‌شه؛ نیازی به نصب چیزی روی سیستم کاربر نهایی نیست.

> این برنامه شماره تولید نمی‌کنه و به تلگرام وصل نمی‌شه. فقط فایل‌های
> مخاطبینِ واقعیِ خودتون رو می‌خونه، نگه می‌داره، و خروجی می‌ده.

---

## بخش ۱ — قابلیت‌ها

### ورودی (Import) — همه‌ی فرمت‌های رایج
| فرمت | پسوند | توضیح |
|---|---|---|
| CSV | `.csv` | استاندارد، جداکننده کاما |
| TSV | `.tsv` | جداکننده Tab |
| متن ساده | `.txt` | یک مخاطب در هر خط؛ برنامه خودش شماره/نام رو تشخیص می‌ده |
| JSON | `.json` | آرایه‌ای از آبجکت‌های `{name, phone, email, tags, notes}` |
| Excel | `.xlsx` | خوندن مستقیم از شیت اول |

فرمت فایل خودکار از روی پسوند تشخیص داده می‌شه؛ ستون‌های انگلیسی و فارسی
(مثل «شماره»، «نام»، «ایمیل») هر دو شناسایی می‌شن.

### خروجی (Export) — همه‌ی این فرمت‌ها
CSV، TSV، TXT (لیست ساده)، JSON، Excel (`.xlsx`) — از کل لیست یا فقط
نتایجِ فیلترشده.

### آمار بر اساس شهر
هر بار که یه فایل ایمپورت می‌کنید، نام دقیق همون فایل به‌عنوان «شهر»
(Source) روی تک‌تکِ مخاطبین اون فایل ثبت می‌شه — دقیقاً مثل قبل. دکمه‌ی
**Statistics (by city)** یه جدول نشون می‌ده: هر فایل/شهر، چند مخاطب،
چند تا شماره‌ی معتبر دارن، چند تا ایمیل دارن، چند تا برچسب دارن.

مثال: اگه یه فایل به اسم `Tehran.csv` و یکی `Shiraz.xlsx` ایمپورت کنید،
جدول آمار دو ردیف نشون می‌ده: `Tehran.csv` و `Shiraz.xlsx`، هرکدوم با
تعداد دقیق مخاطبینشون.

### بدون محدودیت خروجی
هیچ سقف مصنوعی (نه ۱ میلیون، نه هیچ عدد دیگه‌ای) روی تعداد رکوردهای
ایمپورت، ذخیره، یا اکسپورت وجود نداره. تنها محدودیت واقعی، حافظه و
فضای دیسک سیستم خودتونه.

### سرعت
- خوندن فایل به‌صورت استریم (خط‌به‌خط)، نه لود کامل فایل در حافظه
- جدول مخاطبین با `Virtual Mode` → با صدها هزار رکورد هم بدون کندی اسکرول می‌شه
- عملیات ایمپورت روی ترد جدا (Background) اجرا می‌شه تا رابط کاربری قفل نکنه

## بخش ۲ — قدم‌به‌قدم: گرفتن فایل exe از گیت‌هاب (بدون نصب هیچ‌چیزی)

### قدم ۱: ساخت ریپازیتوری
1. وارد [github.com](https://github.com) بشید و لاگین کنید.
2. روی `+` بالا-راست → **New repository** بزنید.
3. یه اسم بدید (مثلاً `contactflow-crm`) → **Create repository**.

### قدم ۲: آپلود فایل‌ها
1. زیپِ پروژه (همینی که الان گرفتید) رو روی سیستم خودتون Extract کنید.
2. توی صفحه‌ی ریپازیتوری خالی که ساختید، روی لینک
   **uploading an existing file** کلیک کنید.
3. همه‌ی فایل‌ها و پوشه‌های داخل `ContactFlowCRM/` رو بکشید و رها کنید
   (Drag & Drop) — از جمله پوشه‌ی مخفیِ `.github`.
4. پایین صفحه، دکمه‌ی سبز **Commit changes** رو بزنید.

> نکته: اگه گیت‌هاب پوشه‌ی `.github` رو موقع درگ‌ودراپ قبول نکرد، از
> [GitHub Desktop](https://desktop.github.com) استفاده کنید (نصب رایگان،
> بعد فقط پوشه رو انتخاب و Push می‌کنید) — مطمئن‌ترین راهه.

### قدم ۳: منتظر ساخته‌شدنِ خودکارِ exe بمونید
1. توی صفحه‌ی ریپازیتوری، تب **Actions** رو باز کنید.
2. یه اجرا با اسم **Build Windows EXE** می‌بینید که خودش شروع شده
   (چون فایل `build-windows.yml` رو آپلود کردید).
3. چند دقیقه صبر کنید تا یه علامت ✅ سبز کنارش بیاد.

### قدم ۴: دانلود فایل exe
1. روی همون اجرای ✅ سبز کلیک کنید.
2. پایین صفحه، بخش **Artifacts** رو ببینید.
3. روی `ContactFlowCRM-windows-exe` کلیک کنید → یه فایل zip دانلود می‌شه.
4. زیپ رو باز کنید → داخلش `ContactFlowCRM.exe` هست. همینه، آماده‌ی اجراست.

هر بار که فایل‌های پروژه رو توی گیت‌هاب تغییر بدید (Commit جدید)، این
مرحله خودکار دوباره اجرا می‌شه و یه exe تازه می‌سازه.

## بخش ۳ — روش جایگزین: ساخت لوکال روی ویندوز (اختیاری)

اگه نمی‌خواید از گیت‌هاب استفاده کنید:

1. [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) رو
   دانلود و نصب کنید (رایگان، چند دقیقه طول می‌کشه).
2. پوشه‌ی پروژه رو باز کنید، توی همون پوشه یه ترمینال (PowerShell) باز کنید.
3. این دستور رو بزنید:
   ```powershell
   dotnet publish ContactFlowCRM.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
   ```
4. فایل نهایی: `publish\ContactFlowCRM.exe`

## بخش ۴ — استفاده از برنامه

1. `ContactFlowCRM.exe` رو اجرا کنید (نیازی به نصب نیست، فقط دابل‌کلیک).
2. دکمه‌ی **Import (any format)...** → فایل مخاطبین واقعی خودتون رو
   انتخاب کنید (csv/tsv/txt/json/xlsx).
3. تعداد رکوردهای اضافه/آپدیت‌شده پایین صفحه نشون داده می‌شه.
4. دکمه‌ی **Statistics (by city)** → جدول آمار هر فایل/شهر رو ببینید.
5. برای گرفتن خروجی: **Export All...** یا **Export Filtered...** →
   فرمت دلخواه (csv/tsv/txt/json/xlsx) رو از لیست فرمت‌ها انتخاب کنید.
6. جست‌وجو: بالای صفحه تایپ کنید، جدول آنی فیلتر می‌شه.
7. تگ‌گذاری گروهی: چند ردیف رو با Ctrl+کلیک انتخاب کنید → **Tag Selected...**

فایل داده‌ها همیشه اینجا ذخیره می‌شه (پشتیبان‌گیری هم از همین‌جا):
```
%AppData%\ContactFlowCRM\contacts.json
```

## بخش ۵ — فرمت نمونه‌ی فایل‌های ورودی

داخل پروژه چهار نمونه هست: `sample_contacts.csv`, `.tsv`, `.txt`, `.json`
— می‌تونید مستقیم اینا رو ایمپورت کنید تا کارکرد برنامه رو ببینید.

CSV/TSV/Excel — ستون‌های پیشنهادی:
```
name,phone,email,tags,notes
```

TXT — هر خط یه مخاطب، شماره هرجای خط باشه تشخیص داده می‌شه:
```
Ali Rezaei, +989121234567
```

JSON:
```json
[{ "name": "Ali", "phone": "+989121234567", "tags": "مشتری" }]
```
